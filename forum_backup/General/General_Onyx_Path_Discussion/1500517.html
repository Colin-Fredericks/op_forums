                                                  Also, as I understand it, the reputation system isn't fully enabled on the forums anyway (probably for the best). So basically everyone has the same reputation and either it's grey because the display for that user is disabled, or full because the display is enabled (there is mouse over text that will display "has reputation disabled" or "reputation0").

                                                  The forum software supports a more robust reputation system where users can be awarded/docked reputation (either by selection forum members, or by every user) as something beyond getting likes for a post. However very few people really use that sort of thing because such popularity contests tend to skew behavior and interactions in negative ways rather than helping foster more community goodwill..
