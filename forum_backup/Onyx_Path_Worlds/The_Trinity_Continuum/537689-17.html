                Man, I hope a single action doesn't have too many rolls attached to it. One of the things I really dig about the New World of Darkness is that it minimizes the amount of rolls combat requires, and with all this other junk about Focus and cooperative Initiative, I'm concerned about how long it should take to resolve actions.
                I'm thinking they will probably collapse multiple rolls into just one roll. So if shooting is Finesse + Aim, and Shooting while running away is Discipline + Aim, you roll the lower of the two pools.

                I prefer there to be a defense roll as well as an attack roll for each exchange in combat, since it would feel more like you are actually doing something when it came time to defend. However, I know a lot of people prefer the "one roll and that's it method" to resolve attacks, so if that is how it plays out I'll deal with it.

                Initiative by the preview appears to be a one time thing, so we aren't talking an initiative roll every turn either.
