    12-07-2018, 02:14 PM
    Please list your errata for the Trinity Continuum core rulebook here.
    • Please address only typos, layout glitches, misplaced elements, and similar errors. If it's merely a matter where you'd have phrased something differently, that's not errata, and should go in a different thread.
    • Please confine comments to posting errata. Discussion should also go elsewhere.
    • Missing art and Page XXs are known quantities and are not being called out at this time. There's no need to list them here.

                                                  Refrences to Red Pool:
                                                  Pg 97 - Jinxed
                                                  Pg 120 - Turning Points - 4th paragraph

                                                  Refrences to Black Pool:
                                                  Pg 73 - Momentum - 2nd paragraph


                                                  Footer issues:
                                                  It looks like some footers that have multiple sections on them list both section names and others don't. Not certain if this is because there is a difference between types of Sections or not. There is not visible difference.
                                                  Example: Pg 35 has both section names (Step One: Concepts|Step Two: Paths). Pg 79 has both The Three Areas of Action and Action-Adventure on the pages but the footer only lists Action-Adventure

                                                  Some footers have multiple section names continue from one footer to the next while others only list the most recent section name
                                                  Example: Pg 149 lists both section names (Who Are Talents?|Inspiration). Pg 151 lists just Inspiration header from pg 149. But page 153 lists both headers (Paths|Creating Talents) and this carries over to the footer on page 155, unlike the prior example.

                                                  Page 53 footer should be Skills (Attributes start on page 54)
                                                  Page 141, 143, 147 footer still shows Storyguide Characters|Antagonists even though this section ended on pg 139
                                                  Page 187 footer shows What Is A Storyguide (found on pg 129) but sections listed on page are What Are Gifts? and What Kinds Of Gifts Are There?
