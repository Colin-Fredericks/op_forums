                                                        Yeah, the logic at character creation seems to be “you start with enough Knacks for your Calling dots and no extras to switch out” which would be fine except that Immortal Knacks cost the same experience as Heroic Knacks, so it seems more strategically sound to take all Heroic Knacks at character creation and buy Immortal Knacks in game to maximize your return.

                                                        Samudra’s recommendation that you start with 5 Knacks of any type, so if you take some Immortal Knacks it means some unused Heroic Knacks have to wait in reserve when you apply them, seems the most sound mechanical solution to avoid optimization at the expense of concept.
