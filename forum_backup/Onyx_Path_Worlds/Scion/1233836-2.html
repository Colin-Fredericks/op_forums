                                Well-Tempered and Motorcycle Jacket both use the "Armored" tag, and its ambiguous as to what that means. (From context, I assume it to be Soft Armor). Well Tempered is also worded a bit weirdly, as the circumstantial bonus that stacks with armor only exists when you're not wearing Armor.

                                The Range table on p120 lists "Discipline" as the Combat Attribute for Long range.

                                The "Empty the Clip" stunt doesn't seem to be aware of the Ammunition Check rules later in the chapter. (It says you just flat run out of ammo, the Automatic Tag says you make successive Out of Ammo checks.)

                                Many movement options allow the use of Might or Dexterity, so some of the Pregens should have more movement dice.

                                Virtue rules are somewhat muddy. The sidebar on page 70 suggests that invoking a virtue can be done with any virtue-appropriate action and doesn't actually give any numbers as to what the bonus is. The rules on page 163 suggest you have to be end on a far end of the track to have the Virtuous Condiiton, in order to benefit from extra dice.

                                    The text on Specialties is inconsistent; Page 97 (Character Creation) describes them as eligible for Skills with 3 or more dots and adding Enhancement 1 to rolls with other Skills; Page 59 (Skill Specialties sidebar) describes them as eligible for Skills with 4 or more dots and adding Enhancement 1 only to rolls with that same Skill (unless it would add up to more than Enhancement 3).
