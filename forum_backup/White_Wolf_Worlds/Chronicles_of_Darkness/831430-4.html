                                                        This is absolutely awesome! I'm going to start brushing off my setting notebooks and putting some finishing touches onto things and try to get a game going with my mates. Looks like some great stuff MachineIV! I especially like that the Thorn and Bramble Contracts lived on. Always my absolute favorite ones. I do have a few little comments for the Contracts though! Nothing major.
                                                        • Cloak of the Elements
                                                          • Do the armor values and damage stack when an Elemental has multiple versions active?
                                                          • For immaterial elements that can't cause damage (Darkness) do you think the Contract should instead reduce penalties caused by sed element?
                                                        • Creeping Dread
                                                          • The Fairest power seems super out of place. Maybe swap the Fairest and Beast powers around with Mirror Walk and let Beasts force someone to run away from themselves?
                                                        • Fang & Talon
                                                          • The mode of transportation power is a bit unclear how it works with birds for flight, and burrowing animals. But, that one feels just to be due to this being a rough copy than any issues.
                                                        • Inanimate Communication
                                                          • Does the Darkling Shadow-Copies work as 100% true copies? If one copied a thumb drive, would it contain all the same information for example?
                                                        • Changing Hours
                                                          • Freeze the Clock: Ah yeah! This Contract. This Contract has always been a bit... tricky. Making an Immovable Object is a weirdly powerful tool. But, the big thing is no duration is given for the effect.
                                                          • The Fairest sub-power really needs a big blurb explaining what happens when you de-age a person. That one I can see being a big confusing.
                                                        • Mirror Walk
                                                          • The Beast version of this seems really out of place. Maybe swap it with the Fairest Creeping Dread? The mechanics of the effect also seem strange. Dramatic Failures are pretty much constantly the 'something terrible happens' bit, and having a power that specifically circumvents that seems weird.
                                                        • Game Master's Table
                                                          • Nothing at all to do with mechanics. The original version of it had a really nice bit of fluff explaining why a Changeling may chose to use different games depending on the situation which was very cool. It'd be brilliant if that could make it in again.
                                                        But, the stuff still looks brilliant! Looking forward to seeing the Court Contract stuff. Unless I've managed to miss it somehow which is quite possible.
