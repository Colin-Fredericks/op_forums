                    Likewise Birth Spirit requires a source of dormant essence to create a Spirit. Should it therefore be a Patterning spell?

                    Death 2 can create Ectoplasm out of nothing. How much ectoplasm does it take to make other death-related phenomena?

                                        Not trying to dogpile here, but to add to that a bit:

                                        It really feels like most of Strill based complaints about the systems stem from a simple issue. Instead of acknowledging that - whatever an individual's personal preferences for game writing styles - the CofD books are written in the natural language style and need to be analyzed from that perspective, a lot of the "problems" identified for "fixing" are really just insisting on reading the text as technical language writing style phrasing.

                                        Which is really a shame because I really do think you're a good critical reader that could help identify and solve problems in the game text, but it's the refusal to engage with the way the books are written that seems to always dominate these things. Hell, I have a feeling it would be a lot more constructive for everyone if you changed your approach to these things from, "my technical reading of the text must mean that this problem is the result of the rules," to, "Help me write the rules in a more technical writing fashion so they work better for my group." The Exalted forum has a number of good threads about the later because the semantics aren't getting in the way of doing something useful.
