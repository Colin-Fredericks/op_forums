                        This one takes a little bit of prep work but if you have an escape route set up that uses parkour (say, ramps on the roofs of building to leap across alleyways) Tools into Tools can allow the Demon to make that course, while giving pursuers a far smaller dice pool.

                        Installing Tools into Toys in your doors can make your entrance ways impassable to picks and crowbars.

                        And with the release of Heirs to Hell, there is any number of embeds that a conscientious demonic parent might use for protecting their child, Tag and Release is obvious, but Embeds like Social Dynamics and Special Someone might be used to vet a child's friends and teachers.
