    welcome_to_the_fall.txt

    12-10-2016, 01:33 AM
    I have been considering lately about the knowledge a starting demon character is assumed to have. How would they know what they know? How does a demon instinctively understand pact and gadget creation? How does a demon have a true understanding of cover or any of their new existence that does not line up with their previous lives as angels?

    What if someone made a text file with the basic knowledge a new demon would find invaluable? Let us say a saboteur or an interrogator was able to gain access to the base "Angel:OS" and slip a hidden file into the next update. This hidden file for added security was made into lich-pin of the OS and the previous versions without this augmentation were scrubbed from the logs and memory before a forced update was triggered. Attempting to remove this file would be high risk with minimal benefit. The file only becomes readable once an angel falls so it does not impede operations and it does not contain any information that is a threat to the machine so it leaves it be, focussing on more pressing concerns.

    Of course this is not the case in the default setting but personally I think this could be an interesting explanation. Yes, agencies in the base setting are likely responsible for new demons being brought up to speed on the basics of their new life but that seems rather mundane to me. This idea of a text file being accessible once an angel falls could also explain a demon who has had no interactions with other demons understanding the basics of their capacities.

    So I guess I am just curious about some feedback on this "welcome_to_the_fall.txt" idea. What does the forum think of this concept?

                              • There needs to be a few bogus versions circulating as traps for the unwary

                              • Going off Hermit's idea, the Files are connected to the the number 5 (created by the 5th agenda, natch), in order to fully comprehend/utilize the files, an unchained needs to have successfully forced a fifth key into their cypher to complete the Pentagram

                                  Pacts and Gadgets are used for creating Covers and utilizing your old Numina in your disconnected forms respectively.

                                  Pacts: ultimately, dx-unit may recurse mortal traits to create zones of lesser alert. dx-unit will be moving around the existing code of It's work. dx-unit must offer a mortal creature a boon in exchange for this, and there must be at a minimum a symbolic gesture that both parties understand and agree to the terms of the pact.

                                  Gadgets: the same techniques used for creating, recycling, and resonating It's infrastructure can be used by dx-unit to store the abilities once reliable as numina.

                                  Cover: dx-unit will have initial cover, though It will know the face that fell. do not deviate from assumed identity, or It will see the face that fell. do not expose dx-unit application singularity, or It will come for the face that fell.
