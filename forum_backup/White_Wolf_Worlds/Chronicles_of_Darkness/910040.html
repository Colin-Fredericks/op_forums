    So, remember the neat terminals from VtM - Bloodlines?

    06-08-2016, 09:58 AM
    I made something similar in Java for my Vampire: the Requiem troupe. It is basically a simulated pseudo-terminal, like a mini-game, running the Aegis Kai Doru's very own operating system AkDOS!

    The code is being released under the GPL 3.0 license (free and open-source, changes also need to be made open source). It runs without a gui, so it captures the look and feel of the terminal from Bloodlines nicely. Since the code will also be available, you could modify it yourself or ask me to modify it for use in your own chronicles. Plus, I'll be adding new features to the program, such as hacking mini-games and random interactions with God-Machines, ghosts, and evil spirits that might possess the terminal in an attempt to communicate with the user.

    Here's the github repo:
    https://github.com/armandosstyl/akdos


    The code will be up in the next few minutes, plus a build with instructions on how to run (needs Java Runtime Environment 1.8).
    Hope you wonderful people will like it and comment so I can improve both my coding and the program itself.

    Greece By Night LARP

                                              Okay, tested today a bit and some thoughts. I generally like features. What I would make to app really shine:
                                              1. Users configuration - You get previously prepared data - like from XML or TXT file - and take usernames, password to it, maybe different variants of access on those. Basically so I could make one configuration file for my PCs group and run terminals on those.
                                              2. Numerating lists - As IT technician, I run a large of DOS programs. Those are made with numeration options like "Choose option: 1- Search 2-Relics 3-Organization". And numbers assinged to options. Then you can use 'y' and 'n' as universal answers on yes/no questions in interface.
                                              3. Redesigning names and such - you run Hunter game, I run Mage - much more logical for me would to use something like name 'Arcanet' instead of 'AkDoS', someone other to use vampires ones ( maybe 'Bloodlines' or some other name for Karthian soft ). I suspect it's only a problem to make texts based on variables names like 'Race1' and 'Faction1' and then loading particular XML file with configuration for Terminal that equal those to 'Vampires' and 'Circle of Crone', respectively. 5*5 model of CoD makes this not so difficult to program, I assume.
                                              4. Please, add e-mail accounts - they were one of highlights of VTMB version. Cryptic massages send to characters in retro 'secured' soft. Could also make separate config file for those, so I could send to my PCs as ST.
                                              5. Auto-completion - when I hit TAB commands are not autofilled.

                                                      So, I've been toying around my original source code since releasing 0.9. The two major features I am in the process of adding, before releasing version 1.0 (hopefully during the weekend) are:
                                                      • Integrated dice roller (menu for inserting character stats, 10s re-rolled, successes calculated, successive attempts at -1, dramatic failures taken into account) for hacking. Not as fancy as the hacking sequence in Bloodlines, but it's important that this was done so I can later focus on moving away from a console-based app and into a gui that will resemble the terminal in Bloodlines. (100% completed)
                                                      • XML-based database. This will allow you to simply edit readable xml files to add or remove elements from the database. (25% completed)
