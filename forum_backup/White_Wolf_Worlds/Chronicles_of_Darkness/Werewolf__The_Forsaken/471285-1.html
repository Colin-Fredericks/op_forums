                                That wouldn't actually involve Influence, you'd just bring a computer spirit over and order it to manifest and use a computer.

                                Alternatively, it could use its influences to enhance the computer abilities of someone using a computer, manipulate a computer so that it's able to do things it probably could have done before but easier, or just outright control it so it could do whatever it wanted, within reason.

                                Influence is five powers, and they all do what their names suggest.

                                • Strengthen - Enhances its Sphere of Influence
                                •• Manipulate - Minor changes within Sphere of Influence
                                ••• Control - Dramatic changes within Sphere of Influence
                                •••• Create - Create a new example of its Sphere of Influence
                                ••••• Mass Create - Create many new examples of its Sphere of Influence

                                By default these changes are temporary, but can be made to last longer or be permanent if a spirit has enough Influence and spends the essence.

                                    Originally posted by That Other Guy View Post
                                    Since we have people who seem to have a firer grasp on Influence than I - what level would a Computer spirit need to, you know, access and use a computer (sayunder threat by an Uratha?)
                                    I'd say that Strengthen can let the computer do something better that it is already doing (or just generally run faster, more efficiently, etc.).

                                    Manipulate can make the computer do anything it can naturally do (so if there would be a way to access the data using the available software and hardware, the spirit can do it at this level). So I'd say access and use would normally be at this level, barring extremely stringent security measures.

                                    Control can make the computer do anything, even if the software would not be readily available or the hardware is lacking, as long as it is something a hypothetical computer could do. Here security isn't really a problem anymore, as the spirit has total control over everything the computer does.
