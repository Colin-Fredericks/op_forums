                Originally posted by milo v3 View Post
                I'm an Australian, if we tried to use seasonal courts we'd just end up with the summer court and then the gentry would all murder the changelings since there is no other court to swap over control to. Also... there were other courts like the directional courts and that light based one. So... it's not really any change in the setting that different locations have different courts.

                In 1e it was "Okay we're assuming you're using the seasonal courts... but other places sorta might have different things but you're going to have to make up tonnes of mechanics for them with no real guidelines beyond three examples. Good luck", in 2e you get "You can have the seasonal courts, directional courts, colour courts, whatever courts fit your freehold, here is how you do it in a few easy steps"....
                Yeah. I think maybe some people consider it a setting thing, but I think the biggest difference is that in 1e, somewhere about 95% of the page count of the game assumed you were playing with the four Amero-Euro-Assumptive Seasonal Courts. Now, except for the pages literally talking about the freehold using them, none of the pages assume you're using them.

                I think the Seasonal Courts worked as a shorthand for some concepts, it helped some players jump in. But I also think it felt distant and arbitrary to others. I found some of the other courts fascinating, but because of the 1e style of supplementary material, none could ever really get much attention. I felt that was a lost opportunity. (Lost opportunity. See what I did there?)


                David A Hill Jr
                Freelance Writer
                Independent Game Designer
