                                                The right answer to the "can you or can not learn on your own" conundrum is simple - it depends on the Chronicle (as trite as it sounds). That's because "how you learn Disciplines" is an important Setting Lever that can be set in multiple positions, and each of these positions can be used to construct setting in a different way, and thus - emphasize different themes and provide different gameplay patterns and features, which results in a unique roleplaying experience.
                                                Very basic example: if you want a game that emphasizes hierarchy, dependency on others and moving inside (or against) the chains of local society, you might set the lever to a value of "needs teachers", simply to make Kindreds need each other and introduce additional trading good to the market.
                                                If you want to focus on more personal game, where each Kindred is more of an island and where hierarchy is less important than individual motivations and agendas (this is a very characteristic type of supernatural stories where you could say that each supernatural individual is their own "player"), you might put it to a value of "may develop freely", because it deemphasizes the mentoring and trading in exchange for more space that can be used on personal growth and characterization.l

                                                There is no single fit all-size answer.

                                                EDIT
                                                And in game-text, it's solved by saying that new Disciplines can manifest on their own, while deliberate "learning" can be done by stalking other Vampires. Which gives GM a choice of saying either "yeah, you have XP for this, you spent it and it decided to manifest" or "nah, go find a teacher".
