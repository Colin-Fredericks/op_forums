                                                        So, one thing to add to this debate is the reason Obfuscate 2 doesn't work on humans. It isn't about size (you can use Touch of Shadow on a door). It's about how relevant humans are to one another. Background-person is way more important to a person than a background-thing, so it takes more "juice".

                                                        So my guess is that (if we're going to be discerning) Obfuscate 1 should result in just the default behavior. Put it another way - you strip away behavior that hinges on your particular identity. Dogs respond with whatever their "default human" behavior is, so if they've been trained to bark at everyone except their master, they're going to bark at you.

                                                        (If we're still being discerning) Obfuscate 2 should only hide things that aren't incredibly relevant to a given subject. So maybe applying Obfuscate 2 to a mouse won't hide it from a hungry snake. If you try to obfuscate a bag of corn, it might not work on a crow. I bet, if you try to use it on one of those piglets dressed in tiger stripes, the tiger that adopted the piglets would see through Obfuscate.

                                                        Obfuscate 3 says that it removes all trace of the user. So we're talking all direct visual images, reflections, sounds, smells, etc. So I'd say that it works across the board.

                                                        Obfuscate 4 says that it works on all senses. You're basically replacing a particular identity with another. And it can work with Obfuscate 2 to trick people about objects. So I'd say it would work on the tiger-piglet example above.

                                                        To be honest though, the idea behind Obfuscate has been stated to as "terrifying invisible murder power, why will nobody help me?" So I feel like I'd only let animals see through the discipline when it's thematic and creepy.
