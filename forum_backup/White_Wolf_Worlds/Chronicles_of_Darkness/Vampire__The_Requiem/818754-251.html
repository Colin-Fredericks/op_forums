                        I'd personally discuss this with the players if needed.

                        The reasoning behind bleeding Vitae on purpose is sound. The balance issue also is relevant. But that's ultimately not a question of what makes more sense or is more supported by RAW, instead it is a question of which of two splats should have the upper hand in this particular in a conflict.

                        So that means the best answer depends too much on the specific chronicle. Making it work on a Werewolf game will highlight vampires as dangerous foes. Making it work on a Vampire game would justify the Uratha avoiding open conflict with Vampires. For a crossover game with players on both sides, it helps define the balance of power between the two splats, so it has to be carefully considered.

                        All in all, I think the best default answer would be actually to have it work for two reasons. First, so you tone down conflict between the two of them. Second, because in a direct fight the Uratha already have the upper hand. But in the end the chronicle can mess a lot with those assumptions.
