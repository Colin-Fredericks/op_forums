                Originally posted by Nephilpal View Post


                The terminology clarification came out of a conversation I had with CAS in which he simultaneously expressed interest in having Deceived able to gain extra power by stalking people to figure them out and yet wanted True Names off limits for cosmological reasons. So I split the difference. You should assume that the brush and the Scribe affinity both grab the lower case true names.
                Which means that the Brush CAN grab a mummy's "true name" but not a mummy's "True Name" (which is still sealed away inviolably). It also means that a Deceived would kill to get the Brush. Yeah, the Deceived will suffer under two long-lasting Derangements as a result, but it's not like they are strangers to Derangements.

                                        The Brush rules were written long before the clarification on how true names/True Names work, so we shouldn't read too much into the nomenclature used in the Brush's description. What makes the most sense to me is that given the new rules we have on true names/True Names, the Brush lets you divine anyone's true name for the "low low" cost of two Derangements (plus the actual activation costs of the Brush). At the GM's discretion, it might also let you divine a target's True Name as well, unless the target is a mummy (although functionally I don't know how much that would matter, since the Deceived name magic we have doesn't give any added "oomph" if you have a target's True Name as opposed to her true name).

                                        I agree that this is arguably weak for a 5 dot relic, but given that (1) a huge chunk of name magic requires a target's true name, (2) learning a true name can be a pain in the ass, and (3) the user of the name magic is never actually sure if they have the true name or not since the roll to learn it is made in secret by the GM, I can see the value the Brush would have for Deceived (or Scribes who learn name magic). Hell, given the penalties applicable to trying to learn a mummy's true name, the Brush may be the only real solution to that problem.

                                        BTW, I could have sworn that there was a Relic that alleviated the effect of Derangements on its bearer, which could offset some of the Brush's curse. Maybe I'm just imagining that though.

                                                            Originally posted by Brian888 View Post
                                                            2) Which Temakh's purview would contain stage acting? I'm assuming the Singer, but I'm not sure about that.
                                                            That's a surprisingly complicated question. Theatre as we know it is the lovechild of poetry, song, dance, and everything in between. And of course, many of those art forms are descended from religious ceremonies. For an Egyptian-like culture like the Nameless Empire, it's just as likely something akin to theatre would have been seen as a religious ritual as it would have an entertainment. Egyptians had satires, interestingly enough, right along side dramas of the gods. This is a broad definition of theatre, though. If you or I wandered into an Egyptian "play", we might not really see it as theatre.

                                                            Which is a very long winded way of saying, uh, all of them.

                                                            Edit: That being said, I haven't read as deeply into BotD as I've wanted to yet, so there might actually be an in-universe answer to this.
