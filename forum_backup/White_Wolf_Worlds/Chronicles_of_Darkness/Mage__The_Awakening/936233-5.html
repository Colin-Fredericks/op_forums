    After rereading the other attainment I actually completely agree with Satchel. Temporal Sympathy is a lot less broader usable post-errata than it was before, but it is still quite useful and in the line with "Permanance" for example. The fate and space 2 dot attainments can be argued to be the most useful, or at least most broadly applicable, but some of the other attainments are pretty niche, too.
    I also agree that the pre errata version is a mess if players start to abuse it. While there certainly may be groups which have no problem using this carefully and mainly narrative, time travell can fuck up a lot of groups and I think it is good that for the time spells that allow it, it is clearly stated how to resolve this. I remember a session in a science fiction game were we got our hands on a warship, which was also a time machine and had just destroyed a planet. We discussed for more than two hours what would actually happen if we travel back in time and destroy the past ship with the present ship before the destruction. Our gamemaster literally started crying!

    Originally posted by lnodiv View Post
    So in addition to not being as unbalanced, the additional reasoning is 'Well, it didn't work that way in 1E'?

    Edit: To be clear, I'm trying to see if I can see any reason for actually implementing this change in my game. I find arguments for balance un-compelling, and I have no investment in keeping things similar to first edition, so if there are other practical differences between the two attainments that I may not be considering that make changing this a good idea, I'd like to know
    Anything you mentioned so far Indov can still be done with the appropriate time spell.

    I would therefore simply argue through simplification. The new temporal sympathy makes it clearer how to influence the past and how to resolve it. Instead of basically be able to use ANY spell via temporal sympathy to influence the past, you now need to use time spells first and foremost. It's kind of what the arcanum is for anyway. Temporal sympathy is now nothing more but rules for how to influence the further past, since this should get more and more difficult.
    Additionally to get BETTER at influencing something with weaker temporal sympathy, you actually need to get better in the TIME arcanum, not just any arcanum.
