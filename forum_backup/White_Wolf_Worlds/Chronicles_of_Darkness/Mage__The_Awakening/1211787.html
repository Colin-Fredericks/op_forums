    Essence-Equivalent for Goetia

    04-26-2018, 10:17 AM
    Hello, everyone! I've been thinking a bit about the different "fuel" out there, and I kind of like the idea of having separate types. So spirits run on Essence, faeries on Glamour, I make ghosts run on Plasm, and then for goetia... I've no idea. I can't think of a good name for goetia-fuel, at all, so I was wondering if anyone has any idea for what to call it?

    Oh, and if anyone has suggestions for something else to call goetia, too, that would be great. It's not a bad name, but it's got too specific connotations for me to want to use it for all sorts of astral entities.
