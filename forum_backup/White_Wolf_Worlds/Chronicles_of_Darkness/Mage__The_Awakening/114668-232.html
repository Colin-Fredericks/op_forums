                            The difference between Enhanced Items and Imbued Items is that the former are items with spells cast on them while the latter are items with spells stored inside them that are cast when the item is used. It is impossible to create an Enhanced Item that can increase the user's Strength because such an effect would have to be cast on the user. Instead you have to create an Imbued Item that casts a spell that increases the user's Strength.

                                                        Hey Inodiv,

                                                        The caster decides whether the spell imbued into the item is persistent (always active) or contingent (triggered by a word, gesture, or condition).
                                                        I have added the quote from the 2E Core, if an Imbued Item casts a spell on another subject, and it is persistent, which as the book indicates always active, then you would gain the effect from holding the sword. Very little else is said about Imbued Items and Persistent Effects, but if I were to use RAI and based on 1E it would seem the effect is provided to whoever holds the item.

                                                        If 2E Imbued Item Persistent does not work this way, and it has to be triggered/activated, then it is not really a persistent effect and is instead a contigent effect.

                                                        If 2E Imbued Item Persistent is a constant effect on the item itself and does not grant it's effects to the wielder/user then to me it is an Enhanced Item since that is exactly what an Enhanced Item is.
