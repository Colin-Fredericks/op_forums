                                        Originally posted by Communist Owl View Post

                                        Mudras can only add up to +6 even if your skill is higher
                                        There is some question about getting to +7.

                                        Or whether it is called at +5 regardless of Order rote speciality - pretty sure this was the intended plan.


                                        For +7 you require membership of the historic order Keepers of the Word, and the Exoteric Arete order merit, which requires you to choose a single skill, and then gives +3 on non-magical rolls, but also treats the skill as if it were an order rote skill of it isn't and gives and extra dice if it already is an order rote skill... So Academics, Expression or Occult...

                                        So by the previous argument, this would still be limited to +5, but since this was written after and the merit requires a skill with 4 dots or more (+ speciality), it seems the intention is clear to allow 4+2 = 6 for order rote skills.
