          I'm not exactly sure what you are asking here, but yes.

          For the WoD, I've run both crossovers that allowed all of the lines, such as Vampires, Werewolves, Wraiths, etc, and I've also run a few things like WoD Silent Hill, and it was freakin' amazing.

          I've had a few Marvel Characters show up in WoD games as well. In one instance I can recall of the top of my head, I had Dare Devil show up as a way to really screw with one character that was using Auspex in an attempt to study the city's population, having fun as I was trying to describe what the player was seeing through his <sonar> vision.

          I've also done a few games that stole a lot from nWoD's Night Horrors series, and included a lot of odd and unique "things", which can range from a Mage that honestly believed he was a Jedi, to Cthulhuian beings, to the X-Men.

          I almost, but never actually got to, play a Celestial Chorus mage that believed he was a 3rd Edition D&D Cleric, trapped in a strange world. (Sort of the opposite of the D&D cartoon).

                          I've used the storyteller system for a lot of things, usually with some moderate alterations.

                          The most successful effort was quite a long time ago, and it was sort of a Dragonlance style home-made world a couple buddies and I worked on over the course of a few years. I used the basic Mage system, sort of combining Quintessence and Paradox as Mana so that the same system worked but Paradox resulted in forced mana costs, potentially damaging the mage if he didn't have the buffer to pay that unexpected cost.

                          It worked pretty well, but the goal was really to provide that dynamic magic system to a more classic D&D type game.


                          I've been sort of working on another adaptation of the ST system, trying to simplify it for kids. Not sure what kind of world I will use with this eventually, something like a D&D world (Hero Kids type stuff) or maybe a Harry Potter thing (kids love the Potter).

                                  I personally like the WoD system for its ability to write up human character concepts better than most other systems.
                                  I've used it to put together an Arkham Horror (Call of Cthulhu board game) chronicle. All of the characters were written up (including from most of the expansions) for the players to choose from to play. Each had some special merit that was just for them.
                                  Aside from that, I've included a lot of the Soul Calibur characters in my Renaissance timelines. The Big Bad for one game was a Spiral Ahroun wielding Nightmare. Was kind of fun.
                                  Let's see.....I've used Highlander Immortals (there was a fan-made supplement for them) in more than a couple of WoD games, though they've mostly been NPCs.
                                  There was a high fantasy Dark Ages game that game included a mixed group of supernaturals that were hunting the last of the dragons (with varying success). That played a lot more like D&D than a traditional DA game.
                                  I have the crossover book for Werewolf the Wild West and Deadlands, but haven't had the chance to run a game using it as of yet.

                                  My wife wrote up an outline to use the WoD system to run a game set in Stephen King's interconnected universe.

                                  Those are off the top of my head, but I think I've got notes at home for a few more games.
