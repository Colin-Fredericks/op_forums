                How would that be better?
                You're conflating "Difficulty" the game term that sets the target number for the dice to count as success, with "difficulty" as in a method to represent that one option is harder to accomplish than another.

                This is not some new or radical concept. This was something done in the "Storyteller Revised" system that was the base of Trinity/Aeon/etc. 1e, Exalted, and Scion 1e: The target number to roll became a set number, and difficulty was measured in how many successes an action requires.

                One of the problems that's been an issue for the WoD since day one, is that there's too many variables for rolls: "difficulty" can come from dice-penalties, increased target numbers, or more required successes, and the books did not establish a function heuristic on which to use when. Combat, being the most mechanically intense part of the game, just highlights how little the base-line rules considered the complexity of having all three of those variables interact at the same time really is.

                It's better because it's easier to understand what your character can actually do, because you don't need university level mathematics to actually figuring out whether a combat option is worth using at all, or if it's situational what those situations actually are.
