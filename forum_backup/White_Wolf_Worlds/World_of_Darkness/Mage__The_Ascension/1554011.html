    Extended rolls for wonders

    09-25-2025, 02:24 PM
    Since Artifacts and Fetishes only need 1 success for activation, I guess a better title would be "extended rolls for Talismans"
    I'm using Forged by Dragon's Fire system for wonders, but if there is something about that in M20 (or any other edition) I'd like to know too.

    So, in FbDF page 53 we have this Talisman called Mater Transmission Portal (Arete 4, Quintessence 5). It's system works like that:

    System: To locate a specific person or place using the portal, the user must first adjust the device by making an Intelligence + Technology ro ll with a difficulty of 5 to see a location, and a difficulty of 7 to
    actually open a portal. After making this roll, the user
    rolls the Device's Arete of 4, subtracting one from the
    difficulty for every success on the Intelligence + Tech-
    nology rpoll (to a maximum of -3). Use the Correspondence Ranges chart to determine the num-
    ber of successes the user must obtain. Both uses of the Device remain active for one full scene.
    If the user rolls well enough to open a portal. she
    can leave the portal closed for a time and simply observe the location, without needing to make a second roll to open the portal later in the scene. (…)
    So, using abilities enhancing magick is a thing for wonders (which I didn't knew) and a lot of this books Talisman use it. Now, the question is: can extended Arete rolls be used as well?

    If not, then that means that the wonder in question isn't able to open a portal to anywhere in the world since the correspondence table requires 6+ successes for that? Moreso, the limit is a portal to somewhere you have visited before, as this one requires 4 successes, and that's considering you can get all 4 Arete successes. Most likely you will only be able to open a portal to a very familiar place.

    This seems to be quite limiting and maybe wonders shouls have extended rolls as well? Any reason for why not? Is there any raw about that?

    If not, how doea your table handle this?

      IIRC the RAW is that Wonders don't do Extended Arete Rolls, period. This is a benefit for true Mages alone.

      That said, the game also has a long tradition of not following its own rules when making stuff, and Wonders are no exception, so...

      Myself, I usually go for a case by case approach with Wonders. I see four alternative approaches here, none of them RAW because RAW simply won't work well for this.

      1- Count successes above 3 in the Ability roll as extra success in the Arete roll, just to buff this up a bit;

      2- Do the Extended Action thing, maybe with custom roll duration for the Wonder;

      3- Reduce the number of successes needed so you can get all the options you want within the 4 possible successes;

      4- Give it a set effect within the options in the table and run it with a single success, find out any other benefit you want for extra successes, this always makes a lot of sense for Wonders.

      You can also simply run it RAW and call it a day. An item that can open portals within the ranges of the table is already good within the scope of what a Wonder does. Wonders aren't meant to be very versatile, they're just a cheap alternative to actually having the Spheres to do the stuff.

              Well M20 doesn't say anything one way or the other about extended rolls for wonders, at least not that I can find, and the section on extended rolls and rituals doesn't exclude wonders. Within the fiction it is easy to see someone struggling with such a device and spending a few turns trying to get a lock on with the device. So I'd say it is reasonable to use extended rolls.

              Also, in many cases it would make more sense for the user to first use the device to see the location or place. That scouting might take 6+ successes if the user doesn't know what he's looking for, but more likely takes 5 successes if he is thinking of a specific place and can describe it. That arguably reduces the Correspondence range of the target to line of site (1) for a subsequent teleportation use.
