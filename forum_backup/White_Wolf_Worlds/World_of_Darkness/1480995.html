                              I've looked at it and there are a couple things:
                              • Redemption is derived from Drive, so it doesn't need to be on the char-sheet at all. When you're in Despair, the Redemption-mechanic is triggering your Drive (which is actually the only time Drive comes into play... yeah, I know, it's weird, so Redemption and Drive are kinda the same actually)
                              • Chronicle Tenets don't need to be on the first page because they have mechanically no effect (maybe something for pg3 or 4)
                              • The Edges & Perks section... They should all have one Header and then subheaders with the lines going straight through. Now some Edges generate items and in one case an animal companion (or multiple). With Asset-Edges the items are even temporary, so that should get reflected on the char-sheet somewhere.
                              • Creed-Fields should be Creed-Field. You only get one for your Creed. And it only needs like three lines. The Creed-Fields are fairly short in terms of word-count.
                              • When it comes to items: In addition to the weapons-section there should be a section for armor.
                              • There should be two sections for the special items generated by Edges: One for the temporary items generated by Asset-Edges, the other for the special ones generated by the other Edges (with "Itemname" (whatever Edge it came from) - Details (all the stuff the Edge makes you decide about it, so some space to note down that stuff) )
                              • The section on the first page where Chronicle-Tenets are I would replace with the Desperation-Track and the Danger-Track. The Desperation-Track is a five-dot-track. Now with the Danger-Track the tricky thing is that it can be five or more dots. The book, though, never explains how to use the Danger-Track and adjust the rating to go higher or not, so I don't know if anybody is actually doing that, the book just lists it as "(Tracker rating varies, default is 1-5)".
