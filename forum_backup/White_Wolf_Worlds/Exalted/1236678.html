    On Municipal Charms

    07-19-2018, 01:25 AM
    I've been thinking a bit about Municipal Charms and Alchemical Cities and ....I don't think we actually need a set of really detailed ones. Largely because a game where everyone was playing cities would look more like Civilization or SimCity than Exalted. And, given the niche nature of Alchemicals, I kinda doubt anyone would be able to justify adding enough rules to the game to actually do that setup justice.

    However, the various NPC cities that you have to deal with in Autochthonia do still exist and their capabilities might become important. Like, if you're chasing a criminal and you want to request the city to activate its Infallible Argus Array to search for them, it would be nice to know how that worked. Fortunately, we're likely to get a book that discusses buildings and landscapes with magical powers, up to and including sentience, in the relatively near future. So it seems reasonable to treat Alchemical Cities as particularly high-ranking manses and maybe they'll be able to justify the wordcount for a set of appropriate new Manse powers in the book.

    It seems much more likely than trying to extend the existing Exalted framework past the point it makes sense.
