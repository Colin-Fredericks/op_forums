                        Originally posted by Sakii View Post
                        Can someone explain to me what i need to download and how to set it up for it to work?

                        * Install git — https://git-scm.com/
                        * Install Java — https://java.com/en/download/
                        * Install Gradle — http://gradle.org/
                        * Open a command line prompt
                        * Download the source code using git from github: git clone https://github.com/anathema/anathema_3e.git
                        * Change directory to the newly created anathema_3e directory
                        * Run: gradle run

                                                            Originally posted by Rahod View Post
                                                            Someone should do a Kickstarter or a petition to have this done. I think there is a lot of people out there willing throw a few bucks at this to bring it back to life.
                                                            We did.

                                                            At $575,000 of contributions, our EX3 Dev Team will collaborate to create the Official EX3 Anathema Character Management Toolkit. This free software has evolved and grown with the development of Exalted, but now it is our aim to collaborate with the Anathema team for anEX3 version that releases with EX3 itself.
                                                            The next Stretch Goal is to enable the creation of an official EX3 Anathema Character Management Toolkit. This free program evolved and grew up alongside the development ofExalted, but what we want to do for the first time is have the EX3 Dev Team and the AnathemaTeam work together during the creation of the book with the aim of having EX3 Anathemaready for use with the release of the book. Our intention is that this support in no way hinder the creation and development of EX3, so our Stretch Goal dollars will go towards helping to make this design collaboration possible. We might need to hire someone from outside the EX3 Dev Team to be the go between, or we might need to fly the Anathema Team to see the design ideas for EX3 that John has etched all over walls and floors of his apartment with his model Daiklaive. Or just buy everybody lots and lots of coffee. In any case, while we can and will support Anathema if we don't hit the Stretch Goal, there's no way we could do it in a timely and collaborative manner without the Stretch Goal.
