                                                    12-09-2020, 12:48 PM
                                                    Originally posted by Sith_Happens View Post
                                                    How do clashes work if one character is using a Charm to make multiple attacks? Is the answer different for acting on the same tick vs. using clash Charms?
                                                    If A is making an attack and B is making five attacks, then A's attack would clash B's first attack, and the remaining attacks would be applied normally against A's Defense. If A is also making multiple attacks, then they clash until one runs out of attacks, after which they're then applied normally. No difference between making a clash normally and using a Clash Charm.
