            12-04-2017, 12:52 PM
            Originally posted by Maudova View Post
            The text says it redirects the attack back on the attacker. Does it use the original attackers roll and successes vs the original attackers defense?
            Yep.

            If it beats the original attackers defense does it use the original attackers damage dice against them?
            Yep.

            For a redirected decisive attack that lands and deals damage, does it reset the original attacker to base initiative, the redirecting characters, or neither?
            The original attacker.

            For resonant characters, can this charm be activated against any attack the fails to beat their parry at any range?
            The Resonant effect just changes the timing rules for when you declare the Charm; you're still limited to reflecting non-physical ranged attacks that target only you.

            Should this evocation have the counter attack or clash keyword?
            Nope, as it's neither.
