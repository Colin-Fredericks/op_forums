                                                    I have a question about crafting artifacts in general, and how some of the Solar Craft charms apply to it.

                                                    First, in Superior Projects, it says that crafting artifacts requires "high-quality tools". Do you feel that these tools are separate from regular, or even exceptional tools, for crafting mundane equipment? Is that something that varies depending on the artifact? Would forging a 3-dot daiklave perhaps only require a really well-stocked blacksmith's shop, but building a lorestone might require specialized crystal-cutting and essence-imprinting tools?

                                                    Second, if artifacts do require such specialized tools, can Craftsman Needs No Tools supply them? It says that it allows a crafter to start basic or major projects without tools or workshop, but is that intended to only apply to its speed bonus, and you can still get tools for higher-level projects? Words-as-Workshop Method, meanwhile, says that "Using Craftsman Needs No Tools with appropriate created Artifacts may allow the Exalt to work on superior or legendary Artifact projects at inopportune moments..." - do you think that clause is effectively expanding Craftsman Needs No Tool's "no tools needed" benefit to artifact creation, or is it supposed to be providing some other benefit?

                                                    Finally, if you think that Craftsman Needs No Tools is not (without upgrading from Words-as-Workshop Method) providing tools for artifact projects, do you think it would be reasonable for CNNT to provide the tool bonus for mundane superior projects, just not the speed bonus? Otherwise, it seems to me that such projects are rather orphaned in the crafting system, since CNNT wouldn't provide tools for them, but the clause in WaWM implies it only helps artifact creation.

                                                            Originally posted by Kelly Pedersen View Post
                                                            I have a question about crafting artifacts in general, and how some of the Solar Craft charms apply to it.

                                                            First, in Superior Projects, it says that crafting artifacts requires "high-quality tools". Do you feel that these tools are separate from regular, or even exceptional tools, for crafting mundane equipment? Is that something that varies depending on the artifact? Would forging a 3-dot daiklave perhaps only require a really well-stocked blacksmith's shop, but building a lorestone might require specialized crystal-cutting and essence-imprinting tools?
                                                            I think "depends on the artifact" is probably the most sensible way to handle that, given the diversity of forms they can take.

                                                            Second, if artifacts do require such specialized tools, can Craftsman Needs No Tools supply them? It says that it allows a crafter to start basic or major projects without tools or workshop, but is that intended to only apply to its speed bonus, and you can still get tools for higher-level projects? Words-as-Workshop Method, meanwhile, says that "Using Craftsman Needs No Tools with appropriate created Artifacts may allow the Exalt to work on superior or legendary Artifact projects at inopportune moments..." - do you think that clause is effectively expanding Craftsman Needs No Tool's "no tools needed" benefit to artifact creation, or is it supposed to be providing some other benefit?
                                                            I don't believe Craftsman Needs No Tools will fulfill the need for those tools, no.

                                                            I'll be honest, I'm not sure what that bit in Words-as-Workshop Method is trying to convey. If you use it to conjure up an artifact tool, I'd think you'd have the tools you need to craft your artifact, and don't see why Craftsman Needs No Tools would be necessary.

                                                            Finally, if you think that Craftsman Needs No Tools is not (without upgrading from Words-as-Workshop Method) providing tools for artifact projects, do you think it would be reasonable for CNNT to provide the tool bonus for mundane superior projects, just not the speed bonus? Otherwise, it seems to me that such projects are rather orphaned in the crafting system, since CNNT wouldn't provide tools for them, but the clause in WaWM implies it only helps artifact creation.
                                                            Mundane superior projects tend to be large-scale stuff, like galleons or castles, where one person working with tools isn't gonna cut it. I don't think Craftsman Needs No Tools would make a meaningful difference; the rest of your workforce is still going to need to be appropriately equipped.
