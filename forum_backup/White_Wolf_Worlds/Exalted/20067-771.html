                Originally posted by Crop Weaver View Post
                Favour Conferring Prana : Are the motes commited ?

                Empowering Shout : if presence if supernal, does the Essence 4+ apply whichever Essence the character has ?
                Yes to both.

                The rules for committed motes are on page 254.
                The rules for Supernals applying to Charm upgrades are on page 122. The definition of a Charm upgrade (the Essence 4+ effect) is on page 255.

                Note that the motes for Empowering Shout are NOT committed.

                    Originally posted by autXautY View Post
                    Can you make a temporary major project slot for a project if you have spare slots?

                    In particular, could you make a temporary major project slot to fuse into a superior slot, so that you have a permanent slot free for any major projects you start in the interim, rather than have to create a new temporary slot for every major project you want to try while working on a superior project?
                    No. The rules wording on page 240 is very clear: you can only make a new project slot if your extant slots are filled.

                    I'd house rule this to a "yes" though. Otherwise, nothing is stopping you from starting a major project to fill a slot, then buying a new slot to bundle into your superior project, then using Craftsman Needs No Tools to finish the major project. It's not even particularly twinky to do that because the game is always encouraging you to use Crafting to solve your problems -- I'm sure you can think up a major project that your character will genuinely want to complete whilst you build your artifact.
