                    Ok, bug narrowed down, thanks a lot for your feedback.

                    It seems the last (not-stable) 5.4 version of Libreoffice wipes the controls cells when you open an ods version, but NOT Libreoffice 5.3 (stable branch).

                    => Workarounds :
                    - Use Libreoffice 5.3.x (ods version ONLY)
                    - Use Libreoffice 5.4.x (xlsx version ONLY)

                    I hope they will fix that problem in the next version of Libreoffice :-/ (I'll send a bug report)
