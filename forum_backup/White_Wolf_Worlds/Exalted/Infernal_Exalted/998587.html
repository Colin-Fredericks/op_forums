    Infernals Homebrew Charm Compilation [2e]

    11-04-2016, 11:23 PM
    Hello Everyone,
    I've been compiling a PDF compilation of the majority of the homebrew charms, and I would like to share it with you all: https://drive.google.com/open?id=0B9...y0tRlMwV2xWdmc

    EDIT: Here's the ODT (Open Office) file that the PDF is generated from: https://drive.google.com/open?id=0B9...UJqZ0N4alRWYlk

    EDIT2: I have been spammed by bots asking for edit access on those two files, they are there to host you to download the files, not for you to get access rights other than viewing. I manually edit the real document on my desktop and then upload it in the same share slot with the updated info. I use this thread to collate user submissions here, and anything you want added I will add with the least changes to formatting I can in order to make it work in Open Office and/or pdfs. Preservation is the idea, not being editorial. Thanks for everyone so far!

    Please let me know if I've missed anything, and I will add them to the archive. I know I'm missing a lot that got taken down with the old wiki, especially the interesting fan-made Yozi.

    PS: I don't own anything in the posted document, and I compile them only to archive them against bitrot. This document is in the public domain, and is covered by the CC0 license, do with it what you will.
