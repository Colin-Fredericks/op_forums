    Originally posted by hippokrene View Post
    Exalted 3rd Core is not representative of anything.
    This is super important for people unfamiliar with the scope of E3 to remember. To recap and elaborate further: The kickstarter wasnt for funding exalted 3, that was already in works. The design philosophy for this edition was to get /everything/ conceptually finished before launch. So not only was the dev team building a new core engine for exalted to run on, they were also doing charm development and system creation for Every Splat. If they found issues affecting one part of th system then changes to that reverberated to every other part they were designing. It taking this long to launch the core system is literally the biggest hurdle, everything else has some amount of work done on it. So its okay to be more optimistic about release times.
