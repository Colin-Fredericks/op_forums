                                        Originally posted by Clophiroth View Post
                                        What´s the intended use of Flame-Borne Interception? Yes, +1 Parry for the rest of the turn, but it is more expensive than using the excellency, and it resets if you are hit. It is clearly intended for "I´m being attacked more than once this turn, would be cool to have extra Parry on all of these attacks", but in that case, you could just... continue using your Excellency, until it is for free.

                                        Maybe I´m just not knowledgeable enough about the mechanics... XD
                                        Stoking Bonfire Style is per enemy, while Flame-Borne Interception is against all enemies. Plus, Flame-Borne grows on its own while Stoking Bonfire you have to decide how high it goes.


                                        So with a hypothetical Melee 5, plus Speciality (max of +3 Parry) DB, versus 3 (or more!) different enemies, I'd use Flame-Borne, as it would be 3m for a +1, then +2, then +3 Parry, while Stoking Bonfire would be 12m for the same bonuses. But against the same enemy attacking three times across three Turns, it would be 9m for Flame-Borne for a +1 Parry on all three turns, while Stoking Bonfire would be 3m (2m for Turn 1, 1m for Turn 2, 0 for Turn 3) for the same bonus (and you could go higher, obviously).

                                        Also, Stoking Bonfire also resets, fyi
