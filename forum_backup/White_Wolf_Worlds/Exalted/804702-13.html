                                            So, if I were writing Ex3 from scratch, here's how I'd standardize things. This is written flowchart style, but can be put in natural language pretty easily. It's actually how things already work, just made much, much clearer, covering basically all the edge cases I can think of.

                                            Charms come in five types.

                                            - Permanent: What is says on the tin.
                                            - Action: This charm is an action in and of itself. There are three types of action charms:
                                            - Dramatic: Lasting beyond the timescale of combat
                                            - Combat: Taken on your turn in combat
                                            - Reflexive: Taken at the start of any tick in combat
                                            - Declaration: Used when declaring an action.
                                            - Response: Used in response to someone declaring an action (after they've used Declaration charms)
                                            - Aftereffect: Used after an action finishes resolving. Often generates new actions to be resolved immediately.

                                            Any time multiple characters want to do something in the same step, resolve ordering conflicts by comparing, in order:
                                            - Initiative
                                            - Wits
                                            - ST's choice

                                            Each action is a series of steps. For each step:
                                            - Active characters uses Declaration charms. Usually just one person, but in opposed rolls, all active characters.
                                            - Any characters use Response charms, and make choices as to how to defend (dodge or parry, applicable intimacies, etc). Active characters usually won't do anything here, but they might in opposed rolls.
                                            - Resolve the step. This sometimes requires a dice roll (or one per active character).
                                            - - Sometimes the resolution results in another step. Start at the top.
                                            Once all steps are completed, characters activate any Aftereffect charms triggered by the resolution of the action.

                                            A reflexive move looks like so. One-step action like this aren't usually broken out in the text, but they still follow the same rules about charm activation (Declaration, then Response, then resolve).
                                            - Step 1: Announce move.
                                            Resolution: move.

                                            An attack works like so.
                                            - Step 1: Attack roll.
                                            Resolution: If it misses, stop.
                                            - Step 1.5: Apply hardness, if decisive.
                                            Resolution: If damage is less than hardness, stop.
                                            - Step 2: Damage roll.
                                            Resulution: If no successes, stop.
                                            - Step 3: Apply damage.
                                            Resolution: Apply damage to the target.

                                            An extended roll works like so:
                                            - Step 1: Make a roll.
                                            Resolution: If cumulative successes >= goal, success. If number of rolls = terminus, failure. Otherwise, repeat step 1.

                                            Instill / Inspire:
                                            - Step 1: Influence roll.
                                            Resolution: If it didn't meet Resolve, stop.
                                            - Step 2: Resist.
                                            If target spent WP, nothing, otherwise, intimacy changes / emotion is roused.

                                            Persuade:
                                            - Step 1: Influence roll.
                                            Resolution: If didn't meet Resolve, stop.
                                            - Step 2: Decision point.
                                            Resolution: If there was a valid intimacy and target spent wp, nothing. Otherwise, they're persuaded.

                                            In combat:
                                            Each round:
                                            - Start with the tick of the highest initiative character.
                                            - Each tick:
                                            - - Any character may take reflexive actions or activate Reflexive Action charms.
                                            - - Any character whose initiative matches the current tick takes their turn.
                                            - - - Taking a turn involves announcing an action, a flurry of them or a Combat Action charm.
                                            - - - Resolve each announced action sequentially (usually one, or two for a flurry, on N for certain combat action charms), if it's valid. If not (it's a decisive attack and the character is crashed, the target is already dead, etc), don't.
                                            - If not all characters have acted, move on to the next tick. If the have, the round is over.
                                            At the end of the round, mote drip triggers, "one round" charms end.

                                            I'm not rewriting the core rules engine though, just the charms chapter, so I'll stick with Reflexive and Supplemental, silly as the division might be. >.>

                                            Sail! I'd have been done with Sail by now if I hadn't been sidetracked by my annoyance with charm types.
