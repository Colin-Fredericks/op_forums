                                            Well, for some it might be appropriate to use Wood Dragon Claw, which is an artefact unarmed weapon, essentially. But only for those that use the hands like claws; Tiger and Black Claw were mentioned as ones that are appropriate. But for Crane, a giant ripping claw isn't really how the unarmed strikes work.

                                            Generally speaking, it's deliberately hard to get artefact stats for unarmed strikes with MA, because they're balanced around the fact that most MAs can be combined, but only by using unarmed strikes, which aren't great weapons. As opposed to, say, using an artefact spear for White Reaper, which is very good, but then you can't combine it with Snake, Earth Dragon and Wood Dragon to do ridiculously enormous amounts of Withering damage.

                                            STing Bronze Age Exalted
