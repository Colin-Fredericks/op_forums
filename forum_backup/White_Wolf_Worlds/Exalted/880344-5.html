                                            Look, honestly, the 'what's happening with X' is almost always going to be answered with 'it's being worked on'. Like, that's the base status for this stuff. It might be in planning stages, it might be in, like, I don't know the selection process if it's outsourced? That bit of 'work' anyway. It might be in the 'drafted but having to sit for a while so that when I shower I am struck by the memory I forgot a vital thing so now I have to go and rewrite it' stage. It might be in the 'waiting for approvals' stage. But all of those are work, y'know? They'll get there, they'll get done, it's okay! I know it's taken a long time to get here, but I very much empathise with the Devs when it comes to 'this isn't a process that is easy to break into chunks for a timeline and having an audience throwing fruit and flowers is unhelpful' thing, as opaque as it is for fans.

                                            It's mostly that I'm friends with the Devs so we spend a lot of time chilling out on Skype together and talking shit, and I'm part of the project too. I'm not, like, an official voice of things.
