                                                    If we want to get into freelancer pay scales in real depth... maybe a new thread? But filler is avoided by the developer setting word counts for a given section (which are usually very tight because there's only going to be so much room in the book). If the freelancer doesn't make good use of their word count, it gets red-lined to hell, sent back to them, and they rewrite. That rewrite isn't "new words" they get paid for. Also, if you turn in filler all the time, you're not going to get hired again. So, the incentive is to write as filler-free as possible so you can get to a new project and write more and get paid again. If you have to rewrite your section 5 times, that's 4 jobs you're not getting paid for (and one developer that's questioning using you again).
