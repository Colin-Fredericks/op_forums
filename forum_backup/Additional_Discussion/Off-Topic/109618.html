                      Not all versions of OpenSSL are vulnerable.

                      Originally posted by Heartbleed.com
                      • OpenSSL 1.0.1 through 1.0.1f (inclusive) are vulnerable
                      • OpenSSL 1.0.1g is NOT vulnerable
                      • OpenSSL 1.0.0 branch is NOT vulnerable
                      • OpenSSL 0.9.8 branch is NOT vulnerable
                      So older devices (e.g. routers) that have older OpenSSL version may not have the bug. Anyways, we are all advised to change passwords etc on the websites that contain sensitive data (e.g. e-banking accounts)
