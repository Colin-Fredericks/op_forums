                                Originally posted by brjedi26 View Post
                                Oh, Gone, I wanted to ask: Recently, I've been using your Blood and Smoke 2 page interactive sheet, and I can save the changes I make to it. I didn't used to be able to do this. Is this a change you've made, or is it something that's changed in Adobe Reader?
                                So far as I know, Reader hasn't changed. For some of the "official" Blood and Smoke sheets, I re-saved them in a newer version of Acrobat and enabled the save feature. I have access to newer version, so I'll do that sometimes for the official ones. I make all my sheets in an older version though, so I don't always go through and re-save them that way, just because it takes some time, and it can be an issue if I think I might have to edit them, if I save over them with the new version it gets harder for me to edit them in the version I use for most of my work.

                                If that makes sense. I use the old one to make the sheets because it works better for the way I make them than the new ones do.

                                So yea, some of the Blood and Smoke sheets have the save feature enabled. The "official" one for the new Demon is that way, but the newer ones I made were made like I usually do them. So if you want to test your Reader, then you could try those.

                                I'll try to do more of that moving forward as I can...

                                I'd love to go back and make all my sheets that way, but since I have 15GB worth of PDF's, I'm not eager to go back and convert them and re-upload them.... maybe one of these years.
