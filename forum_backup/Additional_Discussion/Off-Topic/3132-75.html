                                                "Basic income is hard, we shouldn't try it."

                                                "Basic income might not work, we shouldn't even try."

                                                I'm so sick of seeing this attitude floating around out there when this topic comes up. We didn't know if we could land on the Moon, but we did it. We didn't know if Universal Healthcare would work, but we did it anyway. We had no idea if the telephone or electricity would become a thing, but they did. Can you imagine if Louis Pasteur gave up on his work on anti-biotics because "it might not work"?

                                                Sure, basic income might not eliminate poverty forever. But if it did, that would be HUGE and on that merit alone it's worth trying. No, the system wouldn't be perfect. Can you name a single system that IS perfect? I'm guessing not.
