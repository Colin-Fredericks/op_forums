# Onyx Path Forum Backup

This repository is a backup of the Onyx Path discusion boards as of November 8th, 2026, before they were closed. Permission was given by Ian A. A. Watson, Onyx Path Community Manager.

Files are stored in the `forum_backup` folder.

If you'd like to run this yourself:

1. Make sure you have Python 3.14 or later available.
2. Install `uv` from [https://docs.astral.sh/uv/#installation]
3. Run `uv add forumscraper` in this folder
4. Run `uv run forum_handler.py -h` for more detailed instructions
